CAGR, XIRR, Rolling Returns: ഏതാണ് ശരിയായ Return? — Mutual Fund-ൽ തുടക്കക്കാർ അറിഞ്ഞിരിക്കേണ്ട സമ്പൂർണ്ണ ഗൈഡ്

August 17, 2026

ഒരേ Mutual Fund. ഒരേ കാലയളവ്. മൂന്ന് വ്യത്യസ്ത Returns. ഇത് ഒരു ഗൂഢാലോചനയല്ല — Mutual Fund return measurement-ന്റെ ഒരു അടിസ്ഥാനപരമായ സത്യമാണ്.

ഒരു ഉദാഹരണം: ഒരു popular large-cap Mutual Fund-ന്റെ 5-year return AMC-യുടെ website-ൽ 14.87% ആണ്. അതേ fund-ൽ SIP ആരംഭിച്ച ഒരു നിക്ഷേപകന്റെ Kuvera app-ൽ XIRR കാണിക്കുന്നു: 15.3%. ഒരു research portal-ൽ ആ fund-ന്റെ performance report: "3-Year Rolling Returns: 12% to 42%". ഒരേ fund, ഒരേ കാലഘട്ടം — പക്ഷേ മൂന്ന് വ്യത്യസ്ത അക്കങ്ങൾ. ഇതിൽ ഏതാണ് ശരി? ഏതാണ് ഒരു ആദ്യകാല നിക്ഷേപകൻ ആശ്രയിക്കേണ്ടത്? ഈ ചോദ്യങ്ങൾക്കുള്ള ഉത്തരം ഈ ലേഖനത്തിൽ.

CAGR: Compound Annual Growth Rate — ഒറ്റ തുക നിക്ഷേപിക്കുന്നവർക്കുള്ള Metric

CAGR (Compound Annual Growth Rate) ഒരു നിക്ഷേപത്തിന്റെ വളർച്ചനിരക്ക് ഓരോ വർഷവും ഒരേ percentage-ൽ compound ആകുന്നു എന്ന് സങ്കൽപ്പിച്ച് കണക്കുകൂട്ടുന്നു. യഥാർഥ ജീവിതത്തിൽ ഓഹരി വിപണി ഓരോ വർഷവും കൃത്യം 14.87% കൊടുക്കില്ല — ഒരു വർഷം 30% ലാഭം, മറ്റൊരു വർഷം 10% നഷ്ടം — പക്ഷേ 5 വർഷം കഴിഞ്ഞ് "ഒരേ നിരക്കിൽ compound ആയിരുന്നെങ്കിൽ" ആ നിരക്ക് ആണ് CAGR.

CAGR കണക്കുകൂട്ടൽ — ഒരു ലളിതമായ ഉദാഹരണം

ഉദാഹരണം: ₹1,00,000 ഒറ്റ തുകയായി (Lump Sum) 2019 ജനുവരിയിൽ Nifty 50 Index Fund-ൽ നിക്ഷേപിക്കുന്നു. 2024 ജനുവരിൽ ആ നിക്ഷേപം ₹2,00,000 ആകുന്നു — Nifty 50 ആ കാലഘട്ടത്തിൽ ഏകദേശം ഇരട്ടിച്ചു.

CAGR Formula: (End Value ÷ Start Value) ^ (1 ÷ Years) − 1

Step-by-Step Calculation:

CAGR = (2,00,000 ÷ 1,00,000) ^ (1 ÷ 5) − 1

= 2 ^ 0.2 − 1

= 1.1487 − 1

= 0.1487 = 14.87% per year ✓

ഇതിന്റെ അർഥം: ₹1,00,000 ഓരോ വർഷവും 14.87% വളർന്നു, 5 വർഷം കൊണ്ട് ₹2,00,000 ആയി. Compound interest-ന്റെ ശക്തി ഇതാണ് — ഓരോ വർഷവും gain-ഉം grow ആകുന്നു.

⚠️ CAGR-ന്റെ ഒരു പ്രധാന പരിമിതി: ഇത് Lump Sum (ഒറ്റ തുക) നിക്ഷേപത്തിന് മാത്രം ശരിയായ metric ആണ്. SIP (Systematic Investment Plan) — ഓരോ മാസവും ₹10,000 നിക്ഷേപിക്കുന്ന രീതി — CAGR ഉപയോഗിച്ച് ശരിയായി measure ചെയ്യാൻ കഴിയില്ല. ഇതിനായി XIRR ആവശ്യമാണ്.

XIRR: Extended Internal Rate of Return — SIP നിക്ഷേപകർക്കുള്ള ശരിയായ Metric

SIP-ൽ ഓരോ മാസവും ₹10,000 നിക്ഷേപിക്കുന്നു. ആദ്യ മാസത്തെ ₹10,000 60 മാസം "ജോലി ചെയ്യുന്നു". അവസാന മാസത്തെ ₹10,000 ഒരു മാസം മാത്രം "ജോലി ചെയ്യുന്നു". ഈ timing-ന്റെ വ്യത്യാസം — cash flow-ന്റെ ശരിയായ time value — കൃത്യമായി കണക്കിലെടുക്കുന്ന metric ആണ് XIRR.

XIRR ഉദാഹരണം — ₹10,000/month SIP, 5 വർഷം

നിക്ഷേപ വിവരങ്ങൾ:

• SIP: ₹10,000 per month

• Duration: 60 months (5 വർഷം)

• ആകെ നിക്ഷേപിച്ചത്: ₹6,00,000

• 5 വർഷം ശേഷം Portfolio Value: ₹9,00,000

⚠️ തെറ്റായ Method vs ✅ ശരിയായ Method

Calculation Method Formula Result ശരിയോ?
Simple Annualized (Absolute) (₹3,00,000 gain ÷ ₹6,00,000) ÷ 5 yrs 10% per year ❌ തെറ്റ്
XIRR (Time-Weighted Return) ഓരോ SIP-ന്റെയും actual time weighted 15% per year ✅ ശരി

5% gap-ന്റെ കാരണം — ആരും പറഞ്ഞിട്ടില്ലാത്ത സത്യം:

Simple calculation ₹6,00,000 മുഴുവൻ 5 years invest ചെയ്‌തു എന്ന് assume ചെയ്യുന്നു. ഇത് ശരിയല്ല. Month 1-ൽ നിക്ഷേപിച്ച ₹10,000 59 മാസം market-ൽ ഉണ്ടായിരുന്നു. Month 60-ൽ നിക്ഷേപിച്ച ₹10,000 ഒരു മാസം മാത്രം. ഈ timing difference-ന്റെ exact value XIRR compute ചെയ്യുന്നു.

Rolling Returns: Consistency-ന്റെ True Test

CAGR-ഉം XIRR-ഉം ഒരു fixed start date ഉം end date ഉം ആശ്രയിക്കുന്നു. ഒരു fund-ൽ നിക്ഷേപിച്ചത് 2019 ജനുവരിയിലോ, 2020 മാർച്ചിലോ (COVID crash), 2021 ഡിസംബറിലോ — ഏത് date ആണ് "ശരിയായ" date? ഓരോ time-ഉം different return ആണ്. Rolling Returns ഈ ചോദ്യത്തിന് ഉത്തരം നൽകുന്നു: ഏത് കാലഘട്ടത്തിൽ നിക്ഷേപിച്ചിരുന്നാലും ആ fund എങ്ങനെ perform ചെയ്‌തു?

Rolling Returns — എങ്ങനെ കണക്കാക്കുന്നു?

3-Year Rolling Return — Nifty 50 (2004–2024):

• January 2004 → January 2007: CAGR = +38.2%

Rolling returns കാണിക്കും: ഏത് time-ലും invest ചെയ്‌ത ആൾക്കും consistent ആയ return ഉണ്ടോ? 240+ windows-ൽ 90%-ഉം positive ആണോ? ഇതാണ് ഒരു ഗുണമേന്മയുള്ള fund-ന്റെ ലക്ഷണം.

🟢 CAGR ഉപയോഗിക്കുക — ഇവിടെ:
രണ്ട് funds compare ചെയ്യുമ്പോൾ, Lump Sum നിക്ഷേപത്തിന്റെ growth track ചെയ്യുമ്പോൾ. Zerodha, Groww, ET Money — ഇവ fund page-ൽ 1Y / 3Y / 5Y CAGR കാണിക്കുന്നു. ഇത് quick comparison-ന് ഉചിതം. Fund A-ന്റേ 5Y CAGR 15%, Fund B-ന്റേ 5Y CAGR 12% — ഇങ്ങനെ compare ചെയ്‌തു ആദ്യ screen pass ആകുന്ന fund select ചെയ്യാം.
🔵 XIRR ഉപയോഗിക്കുക — ഇവിടെ:
സ്വന്തം SIP portfolio-ന്റെ actual return അറിയാൻ. Kuvera, Zerodha Coin, Groww-ൽ portfolio section-ൽ XIRR automatically കിട്ടും. "ഞാൻ ശരിക്കും എത്ര return ഉണ്ടാക്കി?" — ഈ ചോദ്യത്തിന് XIRR-ൽ നിന്ന് മാത്രം ശരിയായ ഉത്തരം കിട്ടും.
🟡 Rolling Returns ഉപയോഗിക്കുക — ഇവിടെ:
ഒരു fund ദീർഘകാലത്തിൽ consistent ആണോ എന്ന് അറിയാൻ. ValueResearch, Morningstar India, AMFI-ൽ rolling returns data ലഭ്യമാണ്. "ഈ fund ഏതൊരു time-ൽ invest ചെയ്‌താലും positive return കൊടുക്കുമോ?" — ഇതിന് rolling returns ഉത്തരം നൽകും. 3Y rolling return-ൽ 90%-ഉം positive ആയ fund അർഹമായ ശ്രദ്ധ നൽകണം.

ഉപസംഹാരം

CAGR, XIRR, Rolling Returns — ഇവ മൂന്നും പരസ്പര ശത്രുക്കളല്ല. ഇവ ഒരേ fund-ന്റെ മൂന്ന് വ്യത്യസ്ത perspectives ആണ്. ഒരു ഡോക്ടർ BP, blood sugar, cholesterol — മൂന്നും measure ചെയ്‌ത് ആകെ ആരോഗ്യം assess ചെയ്യുന്നതുപോലെ, ഒരു ബുദ്ധിയുള്ള നിക്ഷേപകൻ മൂന്ന് metrics-ഉം ഒരുമിച്ച് ഉപയോഗിക്കും.

ഒരു fund-ന്റെ 5-year CAGR 15% — attractive. ആ fund-ന്റെ Rolling Returns worst window: −8% — risk. സ്വന്തം SIP-ൽ XIRR 12% — ഈ fund continue ചെയ്യണോ, switch ചെയ്യണോ? ഈ മൂന്ന് ഉത്തരങ്ങൾ ഒരുമിച്ച് ചേർക്കുമ്പോഴാണ് ഒരു informed nvestment decision ഉണ്ടാകുന്നത്.

Mutual Fund നിക്ഷേപം ഒരു marathon ആണ്, sprint അല്ല. ഈ മൂന്ന് tools-ഉം കൈവശമുള്ള ഒരു നിക്ഷേപകൻ ആ marathon-ൽ GPS-ഉം compass-ഉം ഒരുമിച്ച് കൈയിൽ പിടിച്ച് ഓടുന്ന ആൾ ആണ്. ദിശ ആ ആൾ ഒരിക്കലും തെറ്റില്ല.
