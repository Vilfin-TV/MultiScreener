How the agent updates Links
Key needs the operator scope. Host: https://screener-proxy.vilfintv.workers.dev
• Add one link: POST /api/post-link body { "url":"https://…","name":"…","description":"…","days":30 }
• Replace all: POST /api/update-links body { "links":[ … ] }
Rule: for "replace all", first GET https://vilfintv.com/links.json, modify, then POST the FULL array back — or you wipe existing links.

How the agent posts News here
Key needs the publish scope (+ edit/delete for those). Host: https://screener-proxy.vilfintv.workers.dev
• Publish: POST /api/agent/publish body { "section":"<code>","heading":"…","story":"<p>…</p>","photo":"https://…","days":30,"youtube":"https://youtube.com/watch?v=ID","youtube_play":true }
• Edit: same endpoint + "id":"<story id>"  ·  Delete: POST /api/agent/delete { "id":"…" }
Rules: section = an exact code from the dropdown above. story = clean HTML only (<p> <h2> <strong> <ul><li> <a>) — no inline styles, no base64 images. Upload images first via POST /api/upload-image and put the returned URL in photo.
✏️ Editing post — change the fields and click Update.

How the agent posts Stories here
Key needs the publish scope. Host: https://screener-proxy.vilfintv.workers.dev
• Same as News: POST /api/agent/publish with { "section":"story_…","heading":"…","story":"<p>…</p>","photo":"https://…","days":30 }; edit with "id", delete via POST /api/agent/delete.
Rule: use a story_* section code (story_triller, story_travel, story_health, story_comedy, story_kids, story_education, story_animation, story_ai). Clean HTML only; upload images via /api/upload-image first.

How the agent updates Academy (notices + lessons)
Host: https://screener-proxy.vilfintv.workers.dev
• Notices (publish scope): POST /api/agent/publish with "section":"academy_notice" (or academy_cbse / academy_jlpt) + heading/story.
• Lessons (lessons scope): POST /api/agent/lesson body { "hub":"finlit","lesson":{ "unit":"…","title":"…","lead":"…","points":[…],"qa":[{"q":"…","a":"…"}] } }
Rule: hubs = finlit finance micro macro ai programming web info career growth. First GET /api/agent/lessons to avoid duplicate titles. Lessons are appended (built-in lessons never change).
